How a verdict is reached

  1. Reproduce. Your code runs in a sandbox while LeakVerity records every split, fit and score.
  2. Investigate. Execution evidence, data checks and an AI reading of the features flag possible leaks.
  3. Repair. Each leak gets a fix. The corrected code is executed to prove it works.
  4. Measure. The experiment is re-run with every combination of fixes over several splits.
  5. Test the claim. Stability, subgroup and time-based checks probe the claim's scope.
  6. Certify. Fixed rules turn the evidence into a verdict, with hashes for every input.

The AI investigates and explains. Re-executed code produces every number. Pre-registered rules decide the verdict.
